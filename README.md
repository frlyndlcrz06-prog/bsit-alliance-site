# PUPC BSIT Alliance website

Plain HTML, CSS, and JavaScript. No build step.

## Updating the content
Officers only need to edit `data/data.js` (officers, events, announcements, funds).
Officer photos go in the `photos/` folder. The file name must match the `photo` value in `data/data.js`.

## Deploying on GitHub Pages
1. Create a repository and upload all files (keep the folder structure).
2. Go to Settings > Pages.
3. Under "Build and deployment", choose "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Wait a minute. The site appears at `https://<username>.github.io/<repo-name>/`.

## Who can edit
Add officers under Settings > Collaborators. Everyone else can only view the site.
